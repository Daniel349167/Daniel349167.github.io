FieldOps Service Platform
Operaciones de campo, incluso sin conexión

Plataforma personal de órdenes de servicio que conecta una app Android para técnicos, una API Laravel y un panel web de coordinación. El flujo prioriza continuidad offline, permisos, trazabilidad y sincronización segura cuando vuelve la conectividad.

ROLArquitectura + implementación end-to-end
PRODUCTOKotlin / Compose · Vue 3 / TypeScript
BACKENDLaravel 12 · PostgreSQL · API REST
CALIDADPruebas · Docker · sincronización offline

01 / PROBLEMA

El trabajo en campo no puede detenerse cada vez que la conexión se vuelve inestable.

Técnicos y coordinadores deben mantener alineados estados, prioridades, evidencias y responsables sin perder cambios ni depender de registros manuales separados.

02 / DECISIÓN

Una experiencia offline-first en el móvil y una vista operativa central para coordinar.

Room conserva la agenda y una cola persistente; Laravel aplica permisos, idempotencia y estados válidos; el panel Vue permite supervisar la operación desde un solo lugar.
