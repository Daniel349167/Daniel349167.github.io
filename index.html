Dashboard de documentos y estados

Aplicación web personal para registrar documentos y consultar su estado desde un dashboard. Reproduce un flujo de integración con proveedores simulados; no contiene código ni datos de empleadores.

ROLDiseño + implementación Full Stack
STACKVue 3 · Java/Spring Boot · PostgreSQL
ENTREGADocker Compose · GitHub Actions
TIPOProyecto personal · aplicación Full Stack

01 / PROBLEMA

Los equipos necesitan entender qué pasó con cada integración.

El reto es dar visibilidad a operaciones pendientes, rechazadas o completadas sin obligar al usuario a revisar múltiples sistemas o registros técnicos.

02 / DECISIÓN

Una interfaz clara conectada a una API y una base de datos.

El dashboard organiza estados y búsquedas; la API valida la información, conserva el historial y reproduce el flujo completo con proveedores simulados.
